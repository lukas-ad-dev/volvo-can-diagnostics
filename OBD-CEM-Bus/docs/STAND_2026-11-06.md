# Stand 2026-11-06 – funktionierender Live-Stand und Änderungen

- Firmware: **500 kbit/s**, **TWAI_MODE_LISTEN_ONLY**, Boot = STOP.
- Live-Lauf: **289.647 Frames**, **24 CAN-IDs**, **0 Bus-/TX-/RX-Fehler**,
  **33 USB-Queue-Drops** (keine CAN-Fehler).
- TWAI während des Laufs: **RUNNING**.
- Danach sauber **CAN STOP**; der lokale Server wurde beendet und COM8
  freigegeben, damit USB gefahrlos getrennt werden konnte.
- Browseradresse: `http://127.0.0.1:8765/`

## Desktop-Startknopf

Auf dem Desktop liegt:

`%USERPROFILE%\Desktop\Volvo CAN Live.lnk`

Der Knopf startet:

1. den lokalen Diagnoseserver,
2. wartet auf COM8/Firmware,
3. sendet **einmalig** `START` (500 kbit/s, LISTEN_ONLY),
4. öffnet die Web-GUI.

Der Start ist **nicht** mehr durch `kAllowCanStart=false` gesperrt. Die Firmware
startet CAN trotzdem **nicht automatisch beim Boot**; der Start erfolgt nur
durch diesen Knopf, den Browser-Button oder einen expliziten seriellen Befehl.

## Firmware-Änderungen

- `firmware/include/app_config.h`
  - `kDefaultBitrateKbps = 500`, nur `{500}` unterstützt.
  - `kAllowCanStart = true` für den freigegebenen read-only Live-Test.
  - `kPinCanTwaiTx = 48` als Dummy-TX.
- `firmware/src/can_manager.cpp`
  - TWAI ausschließlich `LISTEN_ONLY`, echter TXD GPIO15 bleibt immer
    `INPUT_PULLUP`; TWAI-TX geht auf Dummy-GPIO48.
  - Kein automatischer Start, kein Auto-Neuversuch nach Bus-Off oder
    Installationsfehler.
  - STOP setzt GPIO15 auf `INPUT_PULLUP`, GPIO48 auf `INPUT`.
- Errata: `CONFIG_TWAI_ERRATA_FIX_LISTEN_ONLY_DOM=1` im verwendeten
  `qio_opi`-Framework aktiv.

## Assistent und Bit-Test

- Assistent mit **einem Aktionszyklus**: 10 s Grundzustand, Aktion EIN
  markieren, 10 s aufnehmen, auswerten.
- Kandidaten zeigen **LIVE EIN/AUS**; Zielauswahl pro Kandidat wird beim
  Binden uebernommen.
- **Bit-Test**: nimmt bis zu 60 Bits auf, die sich waehrend des Testbetriebs
  aendern; dauerhaft konstante Bits werden ausgeblendet. Jedes Bit kann live
  beobachtet und frei benannt werden.
- Letzter Abblendlicht-Test im alten Zwei-Zyklus-Modus: 0 Kandidaten, weil
  kein Bit stabil wechselte. Für den naechsten Test den Ein-Zyklus-Assistenten
  oder den Bit-Test verwenden.

## Bekannter Fehler

Der lokale Server schreibt die Session-CSV nicht zuverlässig; die
`session_raw.jsonl` ist vollständig. Für den letzten Lauf wurde daraus eine CSV
erzeugt. Beim nächsten Lauf entweder den USB-Logger verwenden oder den
CSV-Logger im lokalen Server reparieren.

## Sicherheit

- Kein CAN-Senden, keine Diagnoseanfragen, kein Bitratenscan.
- Nur 500 kbit/s, LISTEN_ONLY, expliziter START.
- Hardware-Passivität (Jumper, Kontakte, Isolator/TXD) ist weiterhin **nicht**
  messtechnisch nachgewiesen. Bei Fahrzeugauffälligkeiten sofort **CAN STOP**
  oder USB trennen.
